# 📚 School Management System
A Django-based web application developed during a summer internship at Softpro India, Lucknow, this project aims to digitize and streamline operations for educational institutions.

# 🏫 Project Overview
The School Management System (SMS) provides centralized digital access to manage admissions, academic data, communication, and reports. It serves students, teachers, and administrators through dedicated login panels.

# 🚀 Features
Student Panel: Attendance tracking, profile management, subject access.
Teacher Panel: Attendance marking, subject view, profile management.
Admin Panel: CRUD operations for users, class and subject management.
Enquiry & Complaint System
Email and SMS Notification Integration

# 🛠️ Tech Stack
## Frontend: HTML, CSS, Tailwind CSS, JavaScript
## Backend: Python, Django (MVT architecture)
## Database: SQLite3
## Tools: VS Code, GitHub, Postman (for API testing)

# ⚙️ Modules Overview
Student Information System:	Manage student profiles and records
Login Management:	Authentication and role-based access
Discussion Forum:	Q&A platform for academic help
Complaint & Feedback:	Allow students to submit concerns and feedback
News & Notifications:	Admin posts school updates
Email & SMS Integration:	For registration and enquiry notifications

# 🧪 Installation & Setup
## 1. Clone the repository:
```
git clone https://github.com/your-username/school-management-system.git
cd school-management-system
```

## 2. Create a virtual environment
```
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

## 3. Install dependencies
```
pip install -r requirements.txt
```

## 4. Run migrations and start the server
```
python manage.py migrate
python manage.py runserver
```
